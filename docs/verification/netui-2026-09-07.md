# NetUI 终端代理与交互验证（2026-09-07）

以下记录是在 `rtx4090` 用户安装和服务器 FluxEnv 工作区上，对 v0.2.3 候选修改完成的验证。

## 行为

- 安装器默认安装 Bash/Zsh hook，包括非交互 SSH 使用的 `.bashrc` / `.zshenv`。
- `netup && curl ...` 立即使用当前代理；`netdown` 同步清理 NetUI 拥有的变量。新终端继承运行中的代理。
- 默认 `cn-direct`，旧 `off` 自动迁移。界面只提供 `cn-direct` / `global`，Ctrl+↑ 和 Ctrl+↓ 都循环切换。
- `sudo` 函数通过 `--preserve-env` 传递八个代理变量，并保留参数边界和退出码。
- 渲染避免逐字段创建子进程，导航使用已读取的状态，终端只输出变化的行；缩放和重新进入终端时完整重绘。
- 修复正常退出 TUI 返回失败，以及代理进程恰好退出时可能被误报为身份改变的竞态。

## 环境与检查

本地：Ubuntu 22.04.5 x86_64。服务器：Ubuntu 22.04.4 x86_64、Linux 6.8.0、tmux 3.2a、sing-box 1.13.18。

通过：

```text
bash -n scripts/fluxenv lib/*.sh lib/steps/*.sh scripts/fetch_resources.sh
bash -n packages/netui/bin/netctl packages/netui/lib/*.sh packages/netui/share/shell/init.sh
zsh -n packages/netui/share/shell/init.sh
bash tests/netui/run.sh       # 155 checks; also runs 23 metadata and 43 URI checks
bash tests/netui/install.sh   # install, reinstall, uninstall in a temporary HOME
git diff --check
```

本地未安装 ShellCheck。服务器原本缺少 jq，使用服务器已有的 Ubuntu deb 缓存将 jq 1.6 及其依赖解包到用户目录，并安装用户级启动脚本；没有执行系统包安装。

真实 PTY 检查覆盖三配置导航、两个方向的模式循环、120×24 → 68×18 缩放、光标和备用屏幕恢复、正常退出码。三配置导航响应约 72–75 ms；运行中的实际配置切换模式约 239–291 ms。临时 HOME 和独立 tmux socket 中的真实 sing-box 启停也通过，未操作其他 tmux 会话。

纯渲染对比在同一服务器上使用相同的三个脱敏配置、120×24 窗口，每组 10 帧：平均每帧从 **318.2 ms 降至 15.2 ms**。该指标不含按键解码和业务操作耗时。

服务器的 sudo 要求密码，无法完成实际 root 进程中的环境验证。Bash/Zsh 测试已用替身验证保留的变量名单、包含空格的参数、退出状态及停止代理后的行为；实际执行仍遵循服务器已有的 sudo 策略。

## GitHub 首次访问停顿

实测网关 DNS 的 A 查询正常，AAAA 查询超时。强制 curl 使用 IPv4 仍有约 15 秒的系统解析耗时。代理节点本身使用域名，新的 sing-box 进程首次请求也受影响。

| 检查 | 修复前 | 修复后 |
| --- | --- | --- |
| GitHub API 本机 DNS 查询 | 15.013 s | 自动代理下 0.000024 s |
| GitHub API 完整请求 | 直连 15.352 s | 新 SSH 会话自动代理 0.551 s |
| 新代理进程第一次请求 GitHub | 10.873 s | 三次独立启动分别 1.119 / 1.110 / 0.910 s |
| 部署后实际代理首次请求 | — | 1.097 s |
| 部署后普通 GitHub 请求 | — | 0.531 s |

对当前代理配置增加用户级 bootstrap DNS `223.5.5.5`，Hysteria2 outbound 使用 `domain_resolver`，策略为 `prefer_ipv4`。此 DNS 在服务器上的 A / AAAA 查询分别约 0.218 / 0.240 s，AAAA 正常返回无记录。修改后的配置通过实际 sing-box 核心校验和三次独立进程的首次连接验证。

字段语义依据 sing-box 官方的 [Dial Fields](https://sing-box.sagernet.org/configuration/shared/dial/#domain_resolver) 和 [UDP DNS](https://sing-box.sagernet.org/configuration/dns/server/udp/) 文档，并由已安装的 1.13.18 验证。这个 DNS 调整只应用于该服务器当前的代理配置，没有改变系统 DNS、系统路由、sudoers 或系统服务环境。

新 SSH 会话中直接运行，无需 export：

```text
$ netup && curl -sS -o /dev/null -w 'code=%{http_code} total=%{time_total} peer=%{remote_ip}\n' https://api.github.com/
netui: already running: selab-hy2.json
code=200 total=0.551287 peer=127.0.0.1
```
